# Sample pair

Two fables from *The Aesop for Children* (Rand McNally, 1919), public domain in the United
States, and the matching LibriVox recording. Both are reproduced here so the README example can
be run without downloading anything.

- `aesop-section-37.mp3` is section 37 of the LibriVox recording of *The Aesop for Children*,
  released into the public domain: <https://archive.org/details/aesopforchildren_1308_librivox>
- `aesop-two-fables.epub` is built by `scripts/fetch_samples.py short` from Project Gutenberg
  ebook 19994: <https://www.gutenberg.org/ebooks/19994>

The recording opens and closes with the LibriVox announcement, which has no counterpart in the
text. readalign is expected to trim it, and the run below is what that looks like.
